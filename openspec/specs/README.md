# openspec/specs — Canonical System Specifications

This directory stores **verified and archived** Respire system specifications organized by domain.

- All active architecture & migration specifications are currently staged under `../changes/001-*` through `006-*` (see [../ROADMAP.md](../ROADMAP.md)).
- Once a Change passes independent Verifier sign-off and merges, Scribe merges its `specs/<domain>/spec.md` deltas into this directory.
