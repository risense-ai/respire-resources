# prototypes — 高保真 HTML 原型中心

本目录保存 `respire-client2` 桌面端与 QuickPanel 的高保真 HTML 交互原型、共享设计令牌和确定性 Mock Runtime 接口，作为 **UI 改版的唯一视觉与交互事实源**（参见 OpenSpec `005`）。

- **[tokens/](tokens/README.md)** — 字体、流体 `rem` 比例尺、色彩及状态圆点令牌
- **[mock-api/](mock-api/README.md)** — 对齐 `openapi.yaml` 的确定性 Mock Runtime 与多状态种子夹具
- **`pages/`** — 可直接用浏览器打开交互的独立高保真 HTML 页面
